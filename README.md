## 🧊 About Me

I'm a builder who lives between **two worlds**: the pixels of the browser and the precision of engineering drawings.

On the web side, I craft **glassmorphic, framework-free apps**: frosted panels, soft blur, subtle glow, and smooth animation, all written in plain **HTML, CSS and JavaScript**. On the engineering side, I design in **AutoCAD, CATIA and Fusion**, where every line has a dimension and every dimension has a reason.

Both disciplines taught me the same lesson: **the details are the design.**

## 🧊 The Glassmorphism Recipe

Every project of mine starts from the same handful of ingredients. Here's the core of the look:

```css
.glass {
  background: rgba(255, 255, 255, 0.08);
  backdrop-filter: blur(16px) saturate(160%);
  -webkit-backdrop-filter: blur(16px) saturate(160%);
  border: 1px solid rgba(255, 255, 255, 0.18);
  border-radius: 20px;
  box-shadow: 0 8px 32px rgba(0, 0, 0, 0.25);
}
```

**Ingredients:** a colorful gradient backdrop, a translucent layer, a blur, a thin bright border, and a soft shadow. That's it. ✨
